# MacNotes
to-do list + focus de tarefa diária para manter controle do que está sendo feito naquele momento

## Calendário

O MacNotes pode mostrar eventos do Calendário ao lado das tarefas de um dia. O macOS não
oferece uma permissão somente de leitura para Calendário: é preciso conceder acesso completo
para que o app leia eventos. Ainda assim, o MacNotes trata eventos exclusivamente como contexto:
ele nunca cria, altera ou apaga eventos, nem os transforma em Tasks ou usa para bloquear tempo.

## Calendar

MacNotes can show Calendar events beside a day's Tasks. macOS does not offer a read-only
Calendar permission: full access is required for the app to read events. Even so, MacNotes
treats events solely as context: it never creates, changes, or deletes events, turns them into
Tasks, or uses them to block time.
